# 📊 Student Performance Analysis

A beginner-friendly data analysis project using Python and Pandas to explore student academic performance.

## 🎯 Project Objective

The goal of this project is to analyze student marks in different subjects and identify their average performance.

## 📚 Subjects Analyzed

- Python
- SQL
- Mathematics
- English

## 🛠️ Technologies Used

- Python
- Pandas
- CSV

## 🔍 What This Project Does

- Loads student data from a CSV file
- Displays student performance
- Calculates average marks
- Identifies the top-performing student
- Displays the results clearly

## 📊 Results

The analysis calculates the average marks of each student across Python, SQL, Mathematics, and English.

The project also identifies the student with the highest average score.
